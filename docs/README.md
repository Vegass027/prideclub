# Habit Club — Telegram Mini App для дисциплины по привычкам

Платный маркетплейс закрытых клубов привычек в Telegram с денежными штрафами за пропуски,
социальным контролем и сезонными призами.

## Ключевые решения (TL;DR)

| Решение | Обоснование |
|---|---|
| Telegram Mini App + Bot Gateway | Основная площадка — Telegram, бот как приёмник событий |
| React + TypeScript + FastAPI + PostgreSQL | Стандартный зрелый стек |
| VPS в РФ (Selectel) → миграция на Yandex Cloud | ФЗ-152: ПДн россиян на территории РФ |
| Штрафы в призовой фонд клуба, не P2P | Юридическая безопасность |
| Антифрод через suspicious_pairs + ротацию + FOR UPDATE | Защита от сговора и гонок |
| `service_token` (JWT с aud/iss/exp) для бота | Изоляция пользовательских и внутренних запросов |
