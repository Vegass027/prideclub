# Партнёрский кабинет — функционал для старта (MVP)

## Цель документа
Минимальный набор функций для запуска партнёрской программы с выплатой 30% пожизненно с оплат рефералов.

## MVP-функционал (обязательно на старте)

1. Уникальная реферальная ссылка / промокод
   - Генерируется автоматически при регистрации партнёра
   - Привязывается к аккаунту без ручной настройки

2. Список рефералов со статусами
   - Зарегистрирован
   - Не оплатил
   - Оплатил

3. Доход партнёра
   - Общий заработанный доход
   - Доход "к выплате" (approved / pending)

4. История начислений по каждому рефералу
   - Дата платежа
   - Сумма платежа реферала
   - Начисленный процент (30%)
   - Итоговая сумма начисления

5. Профиль партнёра
   - Реквизиты для выплат (карта / крипто-кошелёк / СБП)
   - Без сложных настроек на старте

6. Уведомления о начислениях
   - Через Telegram-бота (у вас уже есть инфраструктура)
   - Триггеры: новый реферал, новая оплата, статус выплаты изменился

## Что отложить на потом (не нужно на MVP)

- Детальная аналитика по кликам, EPC, конверсии
- Библиотека промо-материалов (баннеры, шаблоны) — на старте достаточно закреплённого сообщения в Telegram
- Мультиссылки под разные каналы/кампании (UTM-конструктор)
- Логи активности (IP, устройства, источники) — на старте проверка вручную
- Автоматические антифрод-алерты

## Логика построения (почему так)

Смысл MVP — оставить только то, без чего продукт теряет смысл. Для партнёрского кабинета это три кита:
- партнёр видит свою ссылку
- партнёр видит статус своих рефералов
- партнёр видит, сколько ему причитается

Всё остальное можно добавить вторым этапом, когда программа наберёт активных партнёров.

## Техническая реализация под ваш стек

Так как у вас уже есть опыт с Telegram-ботами и Supabase, MVP можно собрать как Telegram Mini App или бот-меню:

- Supabase: таблицы partners, referrals (статус, сумма, дата), payouts
- Telegram-бот: команды/кнопки "Моя ссылка", "Мои рефералы", "Баланс"
- Webhook от платёжной системы → обновление статуса в Supabase → пуш-уведомление в Telegram

Срок реализации MVP без отдельного веб-интерфейса: 1-2 недели.
Веб-кабинет с графиками и промо-материалами — второй этап, после появления первых активных партнёров.
