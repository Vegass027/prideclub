# Запуск через лидеров сообществ — пошаговый чек-лист

## Продукт: маркетплейс платных клубов привычек в Telegram
Метод: Community-led growth + Cold Start через "атомарные сети" готовых сообществ

---

# ЧАСТЬ 1. Логика подхода

Вместо холодного трафика в пустые клубы — заход через готовых лидеров мнений
маленьких тематических сообществ (500-5000 живой аудитории). Они приводят
свою аудиторию в клуб под нужную тематику, получают статус капитана и долю
от дохода. Это одновременно решает три проблемы:

1. Пустой клуб — сразу набирается критическая масса через готовую аудиторию.
2. Реальные кейсы — первые чек-ины, штрафы и уловы появляются органически.
3. Качество участников — люди приходят по рекомендации лидера, а не с холодной рекламы.

---

# ЧАСТЬ 2. Пошаговый план действий (от старта до запуска первой волны)

## Шаг 1. Подготовка до контакта с лидерами (внутренняя работа)

- [ ] Определить 3-4 стартовые тематики клубов (планка/спорт, ранний подъём, чтение, отказ от курения)
- [ ] Прописать для каждой тематики: правила, дедлайн чек-ина, размер штрафа, размер депозита
- [ ] Подготовить готовый MVP-механизм чек-ина (даже в ручном/полуручном режиме — Telegram-чат + бот-проверка)
- [ ] Подготовить оферту/условия участия (депозит, штраф, распределение призового фонда)
- [ ] Прописать роль "капитана клуба": что он получает, что от него требуется
- [ ] Определить условия для лидеров: бесплатный доступ + % от дохода / доли из призового фонда (согласуется с моделью 30% lifetime)
- [ ] Подготовить шаблон анкеты для входа участников (см. Часть 4)
- [ ] Подготовить лендинг/пост с описанием клуба для конечной аудитории лидера

## Шаг 2. Составление списка лидеров сообществ

- [ ] Составить список 15-20 микро-лидеров по 3-4 нишам
- [ ] Приоритет: активность аудитории (комментарии, обсуждения), а не число подписчиков
- [ ] Искать в Telegram-каталогах, VK-сообществах, Instagram (хэштеги, Reels, рекомендации)
- [ ] Отметить для каждого: тематика, примерный размер живой аудитории, контакт

## Шаг 3. Контакт с лидерами

- [ ] Отправить персональное сообщение (не рассылку) по шаблону (см. Часть 3)
- [ ] Провести короткий созвон/переписку — объяснить механику, показать демо
- [ ] Дать лидеру выбрать тематику под свою аудиторию
- [ ] Согласовать условия: бесплатный доступ, статус капитана, % от дохода/приза
- [ ] Выдать лидеру готовые материалы для анонса (текст поста, объяснение правил)

## Шаг 4. Подготовка к запуску волны

- [ ] Установить порог запуска клуба: 8-15 записавшихся через лидера
- [ ] Настроить лист ожидания / форму записи (Google Форма, Telegram-бот)
- [ ] Договориться с лидером о курировании набора — отбор через анкету, а не открытый вход всем подряд
- [ ] Указать ограничение мест ("только 15 мест в первой волне") — эффект дефицита
- [ ] Прописать сценарий онбординга нового участника (приветствие, первый тестовый чек-ин, объяснение правил)

## Шаг 5. Анонс лидером своей аудитории

- [ ] Лидер публикует пост/сторис по шаблону (см. Часть 3)
- [ ] Сбор заявок через форму/анкету (2-3 минуты, короткие вопросы — см. Часть 4)
- [ ] Ручной или полуавтоматический отбор заявок (фильтрация по мотивации)
- [ ] Уведомление прошедших отбор о старте волны и дате начала

## Шаг 6. Запуск клуба (первая волна)

- [ ] Открыть доступ только при достижении порога (8-15 участников)
- [ ] Провести приветствие/онбординг: правила, дедлайн, штраф, первый тестовый чек-ин в первые 10 минут после входа
- [ ] Назначить капитана ответственным за модерацию и поддержку атмосферы в чате
- [ ] Запустить реальный отсчёт чек-инов по расписанию клуба

## Шаг 7. Сбор данных и контента с первой волны

- [ ] Фиксировать % выполнения чек-инов за первые 7 дней (норма — от 60-70%)
- [ ] Собирать реальные кейсы: штрафы, уловы, стрики (с согласия участников) для будущего контента
- [ ] Собрать обратную связь от капитана и участников через 1-2 недели
- [ ] Скорректировать анкету/порог входа для второй волны на основе данных

## Шаг 8. Масштабирование

- [ ] Открыть вторую волну по этой же схеме с новыми лидерами/тематиками
- [ ] Формализовать условия лидеров в партнёрскую программу (30% lifetime)
- [ ] Использовать реальные кейсы первой волны в публичном контенте (Reels/Telegram)
- [ ] Подключить публичный набор только после того, как первые клубы показали живую активность

# ЧАСТЬ 3. Шаблонные тексты для лидеров сообществ

## Шаблон 1. Первое сообщение лидеру (личное, не рассылка)

Привет, [Имя]!

Слежу за твоим каналом [название] — нравится, как ты держишь вовлечённость
аудитории вокруг [тема, например: привычки бегать по утрам].

Я делаю проект — платные клубы дисциплины в Telegram: участники ежедневно
подтверждают выполнение привычки видео-кружком, а за пропуск — денежный штраф
в общий призовой фонд клуба. Работает на комбинации личной мотивации и
социального давления сообщества.

Хочу предложить тебе стать капитаном одного из первых клубов под твою
тематику. Что это даёт тебе:

- Бесплатный доступ и статус капитана клуба
- [X]% от дохода клуба / доля из призового фонда
- Готовые материалы для анонса — тебе не нужно ничего придумывать самому
- Твоя аудитория получает первый доступ и приоритетные условия

Готов показать демо и обсудить детали — есть 15 минут на созвон на этой неделе?

## Шаблон 2. Follow-up, если лидер не ответил (через 3-4 дня)

[Имя], привет ещё раз!

Понимаю, что могло затеряться в сообщениях. Коротко: предлагаю тебе бесплатный
статус капитана в клубе дисциплины под твою тему + % от дохода клуба.

Если интересно — скинь 2 минуты, покажу как это выглядит внутри, без обязательств.

## Шаблон 3. Пост для анонса аудитории лидера (публикует лидер от себя)

🔥 Запускаю закрытый клуб дисциплины для тех, кто реально хочет [держать привычку X]

Формат: каждый день подтверждаешь выполнение видео-кружком в общем чате.
Пропустил — платишь штраф в общий призовой фонд клуба. В конце сезона фонд
делится между теми, кто дошёл до конца.

Это не курс и не мотивационные посты. Это реальная ставка деньгами — работает
там, где не работает сила воли.

Кому подходит:
— Пробовал(а) держать привычку и бросал(а) больше одного раза
— Готов(а) на 30 дней жёсткой дисциплины с реальным денежным риском
— Хочешь поддержку сообщества, а не делать это в одиночку

Первая волна — только [15] мест. Заполни короткую анкету, если готов(а) серьёзно:
[ссылка на анкету]

Старт волны — [дата].

## Шаблон 4. Сообщение отобранным участникам после анкеты

Привет! Ты прошёл(а) отбор в клуб [название].

Старт волны: [дата]. Правила клуба:

— Чек-ин: [окно времени], формат — видео-кружок в чат клуба
— Депозит: [сумма] — идёт на штрафы за пропуски
— Штраф за пропуск: [сумма] — уходит в общий призовой фонд
— В конце сезона фонд делится между участниками с лучшим результатом

Ссылка на вход в клуб и Mini App: [ссылка]

Если пропустишь чек-ин — это нормально один раз, но помни: депозит не резиновый 🙂

## Шаблон 5. Сообщение капитану клуба после запуска (поддержка вовлечённости)

Привет, [Имя]! Первая неделя клуба позади.

Статистика:
— Чек-инов выполнено: [X]%
— Штрафов начислено: [X]
— Активных участников: [X]

Твоя роль сейчас — поддерживать атмосферу в чате: хвалить тех, кто держится,
подбадривать тех, кто на грани срыва. Это сильно влияет на удержание.

Если нужны материалы для поста с промежуточными итогами — я подготовлю.

# ЧАСТЬ 4. Шаблон анкеты для входа участников (2-3 минуты)

1. Имя / Telegram-username
2. В какой клуб хочешь попасть? [выбор из списка тематик]
3. Пробовал(а) раньше держать эту привычку? Почему бросал(а)?
4. Почему хочешь зайти именно сейчас?
5. Готов(а) ли ты терять реальные деньги при провале? (да/нет)
6. Откуда узнал(а) о клубе? [имя лидера/канала]

---

# ЧАСТЬ 5. Контрольные метрики первой волны

- Конверсия анкета → оплата: цель 40%+
- % выполнения чек-инов за первые 7 дней: цель 60-70%+
- Retention на 14-й день: отслеживать и сравнивать между клубами разных лидеров
- Количество реальных кейсов (штраф/улов), собранных для контента: минимум 5-10 за первую волну
