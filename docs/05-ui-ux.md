# 05 — UI/UX дизайн-концепция

> Snapshot от 2026-07-22. Палитра и принципы стабильны с initial commit; экраны
> дополнены под текущий код (`MyHabits`, `GlobalLeaderboard`, Admin Mini App).
> Платежи = мок (см. [09-prod-readiness.md](09-prod-readiness.md)).

Дизайн строится вокруг трёх целей: **доверие, мотивация, простота**.

---

## 1. Принципы дизайна

- **Native-first:** интерфейс использует нативные элементы Telegram (Main Button,
  Back Button, `showAlert`/`showConfirm`/`showPopup`, haptic feedback) вместо кастомных
  решений — снижает когнитивную нагрузку, создаёт ощущение "родного" приложения.
- **Автоматическая адаптация темы:** цвета подстраиваются под тему пользователя
  (светлая/тёмная/кастомная) через CSS-переменные Telegram.
- **Один экран — одна задача:** сложные процессы разбиваются на простые шаги.
- **Мгновенная обратная связь:** skeleton-загрузчики, haptic feedback, состояния загрузки.
- **Mobile-first:** крупные кнопки, читаемые шрифты, минимум мелких элементов.

---

## 2. Цветовая палитра

Тёмная тема — основная (совпадает с преобладающим выбором пользователей Telegram,
создаёт "премиальное" ощущение). Светлая — альтернатива, синхронизирована с системой.

### Тёмная тема

| Роль | HEX | Применение |

| Фон (canvas) | `#0F1115` | Основной фон экранов |

### Логика применения

- **Фиолетовый** — главный брендовый, для CTA (Присоединиться, Чекнуться, Оплатить).
- **Бирюзовый** — сигнализирует успех: выполненный чек-ин, рост стрика.
- **Коралловый** — риск/штраф: пропуск, снижение депозита, "можно спалить".
- **Золото** — точечно, для наград и топ-позиций, сохраняет ощущение ценности.

## 3. Типографика

- Основной шрифт: Inter или SF Pro (системный на iOS).
- Заголовки экранов: 20–24px, полужирный.
- Заголовки карточек: 16–18px, полужирный.
- Основной текст: 14–15px, обычный.
- Вторичный текст/подписи: 12–13px, серо-голубой.
- Крупные цифры (баланс, дни стрика): 28–32px, полужирный, акцентный.

## 4. Структура экранов

### 4.1. Онбординг

- Редирект-страница (`/onboarding`): если юзер состоит ровно в 1 клубе → `/habits/:id/today`,
  иначе → `/my-habits`. Никаких onboarding-туториалов в MVP.
- **Первый шаг — `/start` боту** (обязателен для уведомлений). Если пользователь
  открыл Mini App без `/start` — баннер "Нажмите /start у бота для уведомлений"
  со ссылкой на диалог.
- Graceful degradation без уведомлений: Mini App работает полностью, но пользователь
  узнаёт о штрафах только при следующем открытии.
- Согласие с офертой — при первом платеже, через `showConfirm` с ссылкой на полный текст.
- В MVP согласие не запрашивается (платежи мок).

### 4.2. Маркетплейс привычек (`/marketplace`)

- Верх: приветствие с именем пользователя (из Telegram).
- Карточки привычек (сетка/список): иконка/эмодзи, название, цена подписки,
  количество участников, короткое описание правил.
- Кнопка "Подробнее" раскрывает описание.
- "Вступить" → `PaymentModal` (мок, см. ниже) → `POST /habits/:id/join` → переход в Today.
- "Уже состоит" → кнопка «Открыть клуб →».
- Main Button: "Присоединиться" (на карточке, не глобальный).

### 4.2.1. "Мои клубы" (`/my-habits`)

- Список клубов, в которых состоит юзер (`GET /me/habits`).
- Карточка: title + description + статус активности.
- "Открыть клуб →" → Today.
- Empty state: CTA «Выбрать клуб» → Marketplace.

### 4.3. Экран "Сегодня"

- Крупный круговой таймер до дедлайна (визуально доминирующий элемент).
- Статус: ✅ бирюзовый / ⏳ / ❌ коралловый.
- Кнопка "Отправить кружок" → deep link в чат клуба.
- Мини-блок: текущий стрик ("14 дней подряд 🔥") с золотым числом.

**UI для штрафа:**
- `reason = 'caught'` → "Тебя поймал участник {имя}, штраф {сумма} ушёл в фонд клуба."
- `reason = 'window_closed_no_catch'` → "Ты не отметился, штраф {сумма} автоматически
  ушёл в фонд клуба (никто не поймал)."

### 4.4. Экран "Участники"

- Список участников клуба со статусами дня:
  - Бирюзовая точка — чек-ин выполнен;
  - Серая — окно ещё не закрылось;
  - Коралловая точка + кнопка "Спалить" — нарушение зафиксировано.
- При нажатии "Спалить" — нативное `showConfirm` с суммой.
- Лёгкая haptic-вибрация при успехе.
- **Если штраф уже оформлен другим** — кнопка исчезает у всех (через обновление в Redis),
  UI показывает тост "Кто-то уже поймал этого участника" по коду `penalty_already_processed`.

### 4.5. Лидерборд

- Три таба: "Стрики" / "Охотники" / "Доска позора".
- Топ-3 — увеличенные карточки с золотой/серебряной/бронзовой окантовкой.
- Остальные — компактный список с позицией, аватаром, именем, метрикой.
- Своя позиция пользователя закреплена внизу, если он не в топе.

### 4.6. Баланс и депозит (`/profile`, секция "Депозит")

- Крупная цифра текущего депозита (бирюзовый при нормальном уровне, коралловый при
  критично низком).
- Буллеты: «Депозит покрывает штрафы в клубах», «Если депозит пуст — ты выбываешь из клуба».
- История операций: списания красным со знаком "−", начисления зелёным со знаком "+".
- Кнопка "+ Пополнить" → `TopUpModal` (мок, 4 пресета 299/599/999/1999 ₽, `alert()`).
- Кнопка "Вывести" — **не реализована** в MVP (платежи мок).

### 4.7. Профиль (`/profile`)

- **Avatar** (lg): `<img src={photo_url} onError → fallback на инициалы>`.
- **Депозит** (см. 4.6).
- **Мои клубы**: карточки с описанием и кнопкой «Открыть клуб →».
- **Все клубы →**: secondary кнопка → Marketplace.
- Всегда отображается **BottomNav** (не HabitNav) — глобальный контекст.
- **AI-комендант и кнопка "Удалить мои данные"** в MVP **отсутствуют** (см.
  [09-prod-readiness.md](09-prod-readiness.md) — это в v2).

### 4.8. Глобальный рейтинг (`/leaderboards`)

- 3 вкладки: 🔥 Серии / 🎯 Ловцы / 💀 Позор.
- **Группировка по клубам юзера** (не сквозная таблица).
- В каждом клубе: title + кол-во участников + **топ-3** с медалями + кнопка «Открыть клуб →».
- Endpoint: `GET /leaderboard/{tab}/overview` → `{ tab, metric_label, clubs: [{ habit_id, title, members_count, top: [...] }] }`.
- Empty state если нет клубов / нет активности.

## 5. Компоненты интерфейса

- **Карточка привычки:** скруглённые углы (16px radius), мягкая тень/обводка,
  hover/active с уменьшением масштаба (98%) для тактильного ощущения нажатия.
- **Прогресс-бар стрика:** горизонтальная полоса с градиентом фиолетовый → бирюзовый.
- **Круговой таймер дедлайна:** кольцевой индикатор, меняет цвет с бирюзового на
  коралловый по мере приближения дедлайна.
- **Бейджи:** круглые иконки с золотой обводкой у полученных, серой полупрозрачной —
  у недоступных.
- **Уведомления/тосты:** короткие всплывающие сообщения снизу, исчезают через 2–3 сек.

---

## 6. Микроанимации

- Haptic feedback при чек-ине, "спалить", получении награды.
- Анимация конфетти/частиц при закрытии дня без нарушений или получении бейджа.
- Плавные переходы между экранами (300ms ease-in-out).
- Skeleton-заглушки вместо пустых экранов.
- Числа (баланс, дни стрика) анимируются "прокруткой" от старого значения к новому.

---

## 7. Чек-лист качества

- [ ] Интерфейс подстраивается под тему Telegram через нативные CSS-переменные
- [ ] Каждый экран решает одну основную задачу
- [ ] Main Button привязан к главному действию экрана
- [ ] Используются нативные всплывающие окна вместо кастомных модалок
- [ ] Кнопки и интерактивные зоны не меньше 44×44px
- [ ] Skeleton-загрузчики на всех экранах с загрузкой данных
- [ ] Цветовая кодировка статусов консистентна (бирюзовый = успех, коралловый = риск)
- [ ] Haptic feedback подключён к ключевым действиям
